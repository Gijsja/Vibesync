Your coordination loop

1. Define the outcome.
Create a feature with acceptance criteria. Break it into tasks with narrow file boundaries and real test commands.

2. Give work a home.
Start a task to create an isolated Git worktree and a 45-minute lease. Open that directory in your editor or agent. VibeSync coordinates agents; it does not launch them.

3. Verify, then settle.
Verify & settle runs gates in the background and merges passing work. Inspect logs after a failure. Three consecutive failures require human takeover.

4. Finish the contract.
Once every task is settled, run the feature's holistic gate with Settle feature. Park distractions in the incubator along the way.

Recovery.
State and gate logs are checkpointed to the local vibesync/state Git branch. Run vibesync-repair from this repository to restore them. Keep that branch and vibesync/incubator when backing up the repository.

Activity budgets are estimates from local coordination events, not provider account quotas. Gate commands run with your local permissions.
